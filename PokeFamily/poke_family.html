Initial Plan Color Swatch

I intend to make a website connected to a Pokémon api allowing users to search for Pokémon in the and find others in the same egg group. Creating a Pokémon family tree is the intended purpose and Pokémon fans are the intened audience. Javascript will be used to search through the api and turn the info of Pokémon in the same egg group into visual cards that the user can then pick and continue the family tree with. Egg is the logo.
